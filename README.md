# Sarah — Révision Bac Pro MCV

**Sarah, ta prof de poche pour cartonner au Bac Pro MCV.**
Révise, passe des examens blancs, entraîne-toi à l'oral, gagne des badges. Tout est dans un seul fichier, tout reste sur ton appareil.

## ▶️ Ouvrir l'app

- **En ligne (rien à installer)** : 👉 https://roronoazorohaki.github.io/sarah/
- **Hors ligne** : télécharge `index.html` et ouvre-le d'un double-clic.

- **467 questions** sur **17 matières** (11 pro MCV : SONCAS, CAP, calculs commerciaux, argumentation, relation client, prospection, fidélisation, animation, merchandising, gestion, PSE + 6 générales : français, maths, histoire-géo, EMC, anglais, éco-droit).
- **Générateur infini de calculs commerciaux** (TVA, marges, coefficients, remises, panier moyen, rotation…).
- **Modes** : 🎯 Révision adaptative (répétition espacée) · 📝 Examen blanc (20 Q, 30 min, noté /20) · 🗣️ Oral (25 scénarios) · 💀 Survie (3 vies).
- **Gamification** : XP, niveaux et rangs, série quotidienne, combos, 16 badges.
- **Statistiques** : maîtrise par thème et courbe de progression.
